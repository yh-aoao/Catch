# 苹果降速与水果停桌检查：2026-11-10

已修改两个当前目标目录的苹果初速度为1.5–1.7m/s；旧值1.6–1.9。柠檬速度、摩擦、形状与奖励不改。此前成功率数据使用旧苹果速度，不能当作新配置的评估。原JSON完整快照在本目录*.before。

对停稳样本重新设滚动阻力为0，仍有部分样本停稳。因此滚动阻力不是唯一原因；不规则刚体的稳定支撑姿态、碰撞耗能等机制可使其停住。此对照没有单独分解滑动摩擦和法向接触耗能的贡献，不能据此认定形状是唯一原因。

降低速度会增加停桌/晚离桌机会。仅靠提高速度或强行施力不能同时解决任务可达性与真实运动问题。若需要更高的有效发射率，应另行验证起点/姿态分布及其对机械手准备时间的影响，统一用于训练和测试，并报告发射有效率。
