# 28.85模型脱手后手指检查

使用确定性动作、纯移动回合，分别复现网球seed1000、原始球seed1003、棒球seed1013。三回合均入框，但渲染中存在手指相互分离、部分关节持续反向运动的现象。

关节与动作记录表明：脱手确认后直到回合结束，12维手指动作中有9–10维接近±1；策略仍在主动驱动，不是仅由接触释放后的惯性解释。动作被积分到目标关节角并限制到关节限位，持续同号指令会继续推向限位。当前脱手姿态惩罚每回合约-0.17至-0.20，命中奖励+20；两者量级不同。姿态惩罚在确认脱手后用0.15秒渐增，而这些回合仅剩约0.5秒。

已有同步、关节耦合、过伸和姿态惩罚，没有在脱手后停止策略控制。持续极端指令变化小，因此单纯平滑动作不能解决问题。

建议优先加入确认离手后的动作幅度/关节速度惩罚、平滑趋向自然开手姿态的误差约束，强化该阶段同步及软限位，保留抛球发力阶段的自由度。若需要确定性的部署行为，可在球安全离手后切换限速姿态恢复控制；这属于控制器改变，需单独验证释放与再接触风险。
