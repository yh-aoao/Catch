# Roll / Bounce 成功率诊断（2026-11-11）

补充完成 15 组、780 回合，只做诊断，没有修改正式奖励、训练逻辑、物理参数或发射默认值。每组10个环境物理样本，Bounce每组60回合，Roll每组40回合。

## 最关键的发现

同一组当前原始球随机物理参数和完全相同的初始位置、速度：旧三球 Bounce 13.68 模型为55/60（91.7%），当前六球 Bounce 4.84 模型为38/60（63.3%）。初始状态逐项验证一致。因此，该物理条件本身是可以被现有控制器抓住的；当前模型的能力差异值得优先处理。这个对照不能单独区分多目标干扰、训练时长、初始化和学习率等历史因素，也不能直接证明灾难性遗忘。

现有200回合测试中，当前Bounce原始球失败84次，81次曾接触手，40次曾出现过有效持球，但仅6次的最长连续有效持球达到0.05秒，3次达到0.2秒。问题主要在接触后的有效包覆和持球持续性，而非只差一点达到0.3秒。

Roll 231.61苹果失败120次，98次曾接触手，109次已离桌，最终104次不满足区域条件的原因是球在手掌下方。接触可能包括不合适的位置或时机，不能把它等同于已完成正确拦截。

## 与Throw的区别

当前范围：尺寸/半径±5%，质量±10%，地面/桌面滑动摩擦±15%，Roll滚动摩擦长度±20%，Bounce接触阻尼比±10%。接触阻尼比不是恢复系数。
本地Throw实现：球半径0.035–0.045米，相对0.04米是±12.5%；自由关节阻尼0.005–0.02，和Bounce接触阻尼比不是同一参数。质量配置虽为0.035–0.075kg，但代码调用uniform(low,low)，实际固定0.035kg。Throw没有同样的地面/桌面接触参数随机化。
物理参数是在创建环境时采样，回合重置后不变。默认多目标训练28/24环境，通常每类只有4组静态物理参数。远端实际训练如果覆盖了默认值，应以训练保存的配置和provenance为准。

## 建议的优先次序

1. 保留当前基线，使用独立验证集成功率选模型，不只依赖训练奖励；Bounce当前best优于last。
2. 优先从强Catch模型继续扩展到多目标，研究保留旧目标能力的蒸馏/回放；从Track重建Catch分支不是唯一选择。当前Bounce best/last保存配置均为Track不冻结、学习率倍率1；可对照降低联合学习率或Track学习率倍率，避免控制能力退化。
3. 增加物理参数覆盖。优先考虑可安全重采样的参数在reset重采样，或采用更多经过验证的物理profile池，而不只是增加相同4组参数上的训练时长。
4. 半范围适合作为课程训练起点，然后逐步回到当前范围；当前消融不足以证明必须缩小最终测试范围。缩小测试范围改变benchmark难度，不能当作同条件改进。
5. 奖励先针对已有包覆、接触覆盖、相对速度和持球进度做消融；不要先放宽成功条件。现有策略输入没有显式物体尺寸、材质、自旋，可另行研究可观测尺寸/形状特征及历史或循环策略。
6. Roll必须同时报告主成功率和稳定持球率。固定参数261.94模型主成功率62.9%，但稳定持球率0%，主成功率高不等同于物理抓握更稳定。

## 证据与限制

全部回合和失败均保留，物理样本与源文件、checkpoint哈希已校验。随机范围缩放、初始条件一致性均已验证。
各组采用相同发射种子；但同步环境沿用全局NumPy随机数，回合长度分化后，后续观测/动作噪声不完全配对。每组只有10个独立物理样本，回合并非全部物理独立；小幅变化不能视为显著提升。
同一模型在缩小范围下的推理表现，不等同于用缩小范围重新训练后的表现。
