# Throw / Roll / Bounce 泛化对齐提案（2026-11-16）

此文是设计和代码审计结果，不是已经启用的新训练配置。正式奖励、参数范围和模型输入没有修改。

主Throw的物理随机化发生在构造模型阶段；每回合随机发射、PID、噪声等。保留的五类网格评估模板为bottle/bread/bowl/cup/winnercup，但当前throw_object_shape='sphere'会提前返回球体路线，不能把模板列表当作当前实际启用的多物体训练。

运行审计：同一环境10个不同reset种子，质量、半径、物体自由关节阻尼各只有1个取值；发射条件和PID样本变化。一个样本mass=0.035 kg、r≈0.0387835 m，body inertia每轴7.33516e-5；均匀实心球对应2.10582e-5。质量/尺寸修改后没有按几何重算惯量。不能直接把这些旧范围和旧物理实现当作新的统一标准。

## 对齐的对象与物理协议

1. 使用一个共享对象catalog：同一个object_id的几何、名义质量、尺寸、惯量模型及手接触材质一致。统一SI单位和四元数顺序，区分物体材质与桌面/地面的接触对。不同运动不能仅为了提高成功率而给同一个球不同质量/弹性。
2. 公共参数按回合采样、回合内固定：size_scale、mass_scale和相关接触参数。惯量随质量倍率×尺寸倍率平方更新；视觉/碰撞/包围盒同步更新。Throw需要通用的物体更新器，不应直接调用现有仅适用于roll/bounce并假定存在桌面/地面pair的包装器。
3. 当前完整目标范围作为对照版本：尺寸±5%、质量±10%、滑动摩擦±15%；Roll额外滚动摩擦长度±20%，Bounce额外接触阻尼比±10%。阻尼比不是COR，不能把±10%写成恢复系数±10%。Throw飞行阶段没有理由随机滚动阻力；手接触物理必须与其他任务一致。
4. Throw的自由关节阻尼不宜照搬旧值伪装真实空气阻力。使用零或独立验证的阻力模型，保留legacy以便对照。修复质量采样和惯量后应另建版本并重新训练/适应，不能假定旧checkpoint仍保留原性能。
5. 若采用课程：统一相对偏差系数alpha=0→0.5→1（半范围就是尺寸±2.5%、质量±5%、滑动摩擦±7.5%、Roll滚阻±10%、Bounce阻尼比±5%）。这是待验证训练方案；最终测试仍报告相同完整范围，不能靠缩小测试难度宣称同条件提升。

## 目标分配

- 共同核心：original、tennis_ball、baseball，三任务都测。
- Roll扩展：orange、apple、lemon、tomato_soup_can，合计7类。
- Bounce扩展：racquetball、golf_ball、softball，合计6类。
- Throw可从两者并集10类开始：上述6种球+3种水果+1种罐头；这是建议范围，不是已完成的Throw接入/可抓取性验证。之后再引入非滚动、非弹性物体。
- 类别数不必强行相同；训练时各目标均衡。共用对象上的参数组合使用匹配种子，以便跨任务比较。

## 发射、机器人与评估

- 发射保持任务相关：Throw空中抛射，Roll桌面无滑动初态，Bounce合理材质下弹跳。各自用独立被动物理检查验证离桌、首次反弹、飞行时间、机器人可达区；不依靠持续外力，不在最终统计中悄悄过滤失败发射。
- 机器人参数随机化与物体参数随机化分组配置。建议分离object/launch/robot/noise随机数流，避免并行数和回合长度改变其他环境采样，也便于按同一物理样本做消融。
- 保留固定物体基线、范围内参数随机、未见物体三类评估；已训练物体换参数不等于未见物体泛化。验证集与最终测试的物理种子/发射种子分开。
- 保留任务自己的Track指标；Catch另报统一的持续持球指标（持续时间、低相对速度、真实手接触且无外部支撑），捕获区域按几何定义。当前Roll的区域保留成功率与Bounce连续受控持球成功率不同，不能仅横向比较百分比。

## 当前发现与建议优先级

- 当前Catch失败大多曾接触手。先检查接触质量和持续抓握，不只延长Track训练。
- Roll的_capture_point、scoop奖励和grasp_terms以局部+Y作为掌面法向；Roll/Bounce同一手模的PCA薄轴与+Z点积约0.963，正弯使指尖向+Z移动约5.28 cm。存在坐标定义不一致，值得先做新版本几何/奖励修正对照。它是明确的实现疑点，但尚未通过新训练证明修正后的成功率增益。
- 缩范围推理实验只检验现有模型对物理扰动的敏感性，不能直接证明用半范围重新训练会更好。若固定目标参数仍低，不能把主要原因全归到目标随机化。
- 推广多目标时可比较强三球Catch初始化、旧目标蒸馏/回放、较小联合学习率和Track分支学习率倍率。用固定验证集成功率选模型，保留旧版本和原指标。
