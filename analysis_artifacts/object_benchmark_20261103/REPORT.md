# 新增目标运动验证

七种目标各10条被动轨迹，共70条均通过检查；这是运动与数值验证，不是模型抓取成功率。水果为塑料YCB模型的凸包，罐为侧放解析圆柱，球为各自材质/惯量的解析球。

|目标|轨迹通过|自然离桌时间 / 首次反弹净高度|
|---|---:|---|
|orange|10/10|0.454–1.030秒离桌|
|apple|10/10|0.652–1.172秒离桌|
|lemon|10/10|0.468–1.266秒离桌|
|tomato_soup_can|10/10|1.074–1.924秒离桌|
|racquetball|10/10|0.654–0.844米|
|golf_ball|10/10|0.643–0.842米|
|softball|10/10|0.482–0.629米|

45项测试通过；4条64步短PPO训练链路通过；每新球2局真实策略预计算及逐帧恢复通过；旧三球两任务6个检查回合与原数据initial/final/reward/success完全相同。

所有材质/摩擦是有来源标注的仿真先验，不是实物测量；高尔夫球COR0.8尤其是工程假设。水平反弹窗口是发射设计目标，不是机械臂IK可达性证明。更长保持及新增目标抓取成功率未做正式评估。

水果默认更近释放，不能把它们和旧三球不同初始条件下的成功率直接当作纯物体差异。正式benchmark应固定并报告每组发射协议、物体尺寸质量、可达率及稳定持物标准。
