# 固定参数三球Catch模型在随机物理下的测试

模型Roll270.37 / Bounce13.68，不训练、不改权重。physical_dr_v1开启；每球4套参数×5回合=20回合，seed41000。尺寸±5%、质量±10%、摩擦±15%；Roll滚动阻力±20%，Bounce接触阻尼比±10%。惯量与碰撞/视觉同步更新。每环境物理参数固定，每回合随机发射轨迹。已核对实际物理采样元数据。

模型目录未附服务器原始resolved_config，本次使用已保存的三球/多目标Catch重建设置。只含原始球、网球、棒球；三球目标目录对旧三球走同一physical_v1/v2路由。

结果说明本次小幅物理扰动没有使旧三球策略整体失效。不能据此认定随机化训练一定更好或更差，需用相同测试样本比较训练组。
