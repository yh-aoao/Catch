# BasketThrowFirst训练失败复核（2026-10-28）

## 31.80的含义

复核目录：`outputs/BasketThrowFirst/2026-10-28/01:17:01`。
直接解析该目录TensorBoard事件文件，共636个采样周期：

| 指标 | 结果 |
|---|---|
| 最后记录的环境步数 | 1,304,576 |
| 历史最高平均奖励 | 31.8026，在第4096步出现 |
| 最后平均奖励 | 7.4695 |
| 最后回放成功率统计 | 95.465% |
| 最后移动成功率统计 | 0.0812% |
| 记录过的最高移动成功率统计 | 1.2850% |

旧终端只打印`Current Best`，它是历史最大值，并不是当前奖励。
最早完成的回合主要是较短的固定目标回放，早期混合平均奖励偏高；
`best_reward_31.80`因此代表一个非常早的候选模型。
这里的成功率是现有AverageScalarMeter的训练统计，非独立200回合评估。
训练曲线在`analysis_artifacts/basket_failure_audit_20261028/training_curves.png`。

## 隔离持球等待的诊断

固定底座、固定原近目标、原39.44模型，保持同一套物理模型：
等待期间仅用关节控制器保持原杯状姿态，不移动球、不施加额外托举力。
等待结束后再运行旧Actor，每档5个种子：

| 出手前等待 | 旧Actor反馈控制 | 重放一次成功轨迹的动作序列 |
|---|---|---|
| 0秒 | 5/5 | 5/5 |
| 0.1秒 | 0/5 | 0/5 |
| 0.3秒 | 0/5 | 0/5 |
| 1秒 | 0/5 | 0/5 |
| 2秒 | 0/5 | 0/5 |

没有底盘移动也出现退化，支持“旧技能依赖开局状态、未覆盖稳定持球后的出手”的判断。
动作序列重放也失败，提示不仅是Actor输入改变，真实球/手接触状态也有变化。
这些是小样本诊断，不据此断言某个单独物理因素是唯一原因。

另一个种子的重置检查发现球与手几何有约0.01379m负接触距离；
球Z从初始0.6353m，在保持姿态0.16秒后降至约0.6120m，手指实际角度也发生变化。
需要检查初始穿入、接触稳定化和持球姿态，不能将旧开局投掷成功直接视作通用投掷技能。
当前证据尚未证明初始穿入就是全部原因。

## 已修正的训练报告和选模

- 终端同时显示`Current Reward`、`Best Reward`、`Mobile SR`、`Replay SR`；无完整样本显示n/a。
- 混合训练至少积累50个完整移动回合，才选择best_reward，避免开局短回放回合占据历史最高。
- best_success继续按移动成功率选择，回放不计入该指标。
- 新保存的移动模型记录步数、epoch、当前奖励和分组成功统计，方便追溯权重来源。
- 87项相关测试通过，并完成真实短训练检查日志和保存路径。

这些修改改善可观测性和选模，**没有使当前移动策略学会入框**。
本次未替换现有权重，也未开始新一轮长训练。

## 下一步的训练目标

先解决固定基座下“稳定持球之后仍能投中”，再接回已经训练的停车模块。
训练/验证应覆盖不同持球等待时间，而非只回放开局立即投掷。
初始接触应检查穿入并建立稳定、物理一致的持球起点；新策略不应依赖重置瞬态。
在这个前提验证通过前，继续同一移动训练或增加即时回放比例都缺少有效依据。

本报告没有把这项后续训练描述为已经实现或保证收敛。
