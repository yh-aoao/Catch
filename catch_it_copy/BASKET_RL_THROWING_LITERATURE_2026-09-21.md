# Basket 强化学习投掷文献与设计建议

检索日期：2026-09-21。依据论文原文，未修改训练代码。本文是技术调研，不是穷尽性综述；预印本年份不等同于会议发表年份。

## 1. 最值得借鉴的论文

### Dynamic Handover: Throw and Catch with Bimanual Hands（2023 预印本）

[原文](https://arxiv.org/html/2309.05655v1)，§3、§4.1、Appendix E。

XArm-6 + Allegro 灵巧手，MAPPO 学习抛接。投掷端实际只开放机械臂第 2、3 关节，其余臂关节固定，手指参与控制。

奖励由目标距离项、朝接球端的速度项、力矩惩罚组成：

`r = r_distance + clip(v_ball · u_target, -0.1, 0.1) - 0.003 ||tau||²`。

距离项用指数衰减；原文距离表达式的标量范数记法不完整，移植前需核对实现，不能把网页公式直接复制为代码。作者报告去掉速度项容易握球不释放，去掉距离项则只会用力向前抛。

借鉴：手臂与手指共同学习，同时先降低机械臂探索维度。其近距离双手传递不等于我们的远距离入篮。

### Whole-Body Dynamic Throwing with Legged Manipulators（2024 预印本）

[原文](https://arxiv.org/html/2410.05681v1)，§III-A、III-C、III-D，式 (1)、(4)。

PPO 学习关节动作及夹爪开闭。投掷奖励为 `1 - min(E / d_target, 1)`；E 是预测自由飞行轨迹与目标的最小欧氏距离。球离末端超过 25 cm 时发放一次，通过弹道预测减少奖励延迟。

作者发现过早强调稳定性可能抑制动态动作，通过课程逐渐开放身体动作、增加稳定要求。夹爪是简化的单执行器开闭，不能忽略它与 LEAP 多关节手的差别。

借鉴：学习能命中的释放状态，而非唯一参考速度。最小轨迹距离不等于穿框，移植须保留真实圆框穿越成功判定。

### Throwing Objects into A Moving Basket While Avoiding Obstacles（2022 预印本）

[原文](https://arxiv.org/html/2210.00609v1)，§III-B。

奖励：撞障碍物 -10；入篮 +1；否则负的物体—目标距离。一次完整投掷后结束 episode。

关键条件：预先构造投掷轨迹，RL 的四维动作只调整肩关节起点、终点、轨迹执行时长和释放时间。因此简单奖励可以工作，但并非让机械臂与所有手指逐步从零探索。

借鉴：把释放时机与加速轨迹作为明确的学习变量。可作为低维投掷基线，不宜直接替代并宣称等价于现有端到端控制。

### Training and Evaluation of Deep Policies Using Reinforcement Learning and Generative Models（JMLR 2022）

[期刊页](https://www.jmlr.org/papers/v23/20-1265.html)；[全文](https://www.jmlr.org/papers/volume23/20-1265/20-1265.pdf)，§6.1、6.3、6.4。

Basketball 奖励是球经过篮筐高度时的最小水平误差取负，在 episode 末给出。原任务允许落地反弹，不能原样用作直接入篮标准。

GenRL 从示教及扰动轨迹训练生成模型，再在低维潜空间搜索平滑动作序列。作者在其 PPO/SAC 对比实验中观察到动作采样引起抖动、开局掉球；这只是该实验结论，不能推出 PPO 普遍无法投掷。

借鉴：排查时序探索和初始握球，不要只增加奖励项。可尝试参考动作预训练或平滑轨迹参数，但需要独立对照。

### Bridging the Sim-to-Real Gap for Athletic Loco-Manipulation（2025 预印本）

[原文](https://arxiv.org/html/2502.10894v1)，Appendix B-A。

准备、投掷、恢复分别奖励；投掷阶段为 `20 max(v_x,0) + 20 max(v_z,0) - 0.5 |v_y|²`，其中 x 为前向、z 为向上。准备阶段有参考动作。

注意它使用接球斗，且在准备期间放入球，目标也不是灵巧手精准入篮。只适合借鉴前上方加速和参考动作，不应复制任务装置、状态设置或绝对坐标轴。

## 2. 对现有 Basket 的判断

当前 `gym_dcmm/utils/basket_catching.py::joint_throw_reward` 包括有限持球信用、参考速度匹配历史最佳值的增量、一次释放奖励、飞行接近进度、控制和平滑惩罚、成功和失败奖励。

用户历史日志显示最后接触约 0.044 s，球速约为前向 0.63 m/s、向上 0.51 m/s，而参考速度约为前向 2.96 m/s、向上 3.33 m/s。证据支持“很早脱手且速度不足”，不能单靠这些日志断定是初始姿态、采样噪声还是手臂控制导致。

参考速度匹配可能提供有用引导，但特定参考解不是唯一有效弹道；只有历史最佳值改善才奖励，也可能让后续准备过程反馈弱。上面这些是待验证假设，不是已证明的失败根因。

## 3. 建议的最小实验路线（项目建议，非论文原方案）

1. **验证物理起点**：固定底座、单一目标、单一球参数。保持初始关节目标，检查球能否自然稳定留在手内；随后用一条平滑臂动作检查能否通过真实接触产生足够速度。记录球速度、接触时长、关节目标与实际速度、释放时刻。只初始化摆放球，不在挥臂时绑定、托举或注入球速。
2. **获得单任务抛球基线**：先联合学习手臂和手指，暂时不同时解决底座定位。可限制部分臂自由度作诊断，但需报告限制。固定手指的 Track 能否实现释放取决于手形及动力学，不能默认一定可行。
3. **结果奖励优先**：释放时用真实位置、速度预测飞行误差，给一次连续质量奖励；真实穿框单独给成功奖励。倾斜圆框使用实际平面法向，不能只比较世界 z 高度。
4. **补充可控的探索引导**：在真实持球且加速阶段，提供有上限的朝目标、向上速度引导。目标方向使用几何向量。不能长期无限奖励速度，避免乱甩；正则项以归一化后的实际贡献评估，不直接复制别的机器人的系数。
5. **再增加难度**：确认会真实抛球后，扩展目标距离、横向位置，再恢复底座参与及两阶段训练。固定底座实验是排错基线，不改变最终多任务移动操作主线。

可测试的奖励骨架：

`r_t = w_hit * I_actual_hoop_crossing + w_release * I_first_release * Q_flight + w_acc * I_held_acceleration * A_t - regularization - failure_cost`。

其中 `Q_flight = exp(-E² / sigma²)` 是候选连续质量函数，系数需经实测标定。预测不能穿过框面时也要给有限、连续的近失误反馈，避免所有初始尝试都是零分；但该反馈绝不计为命中。

入篮判定与辅助奖励分开：球必须脱手、自由飞行并从正确方向穿过有效圆框区域。`E` 的设计要排除仍持球靠近框形成的假进步。准备、加速、飞行是 episode 内事件，不等于强制改回早期的停车—交接控制结构。

## 4. 验证指标与消融

- 初始持球存活时间、提前脱手率、有效释放率。
- 释放前向/向上速度分布、真实飞行距离、框平面误差、真实入篮率。
- 各奖励项 episode 总和，避免只看 best reward。
- 同一初始分布下比较：现有奖励；连续飞行质量奖励；再加平滑探索/动作先验。每组使用多个种子、相同交互预算，避免同时修改奖励、动作、初始化而失去归因。

最优先阅读：Dynamic Handover（近似硬件与手指协同）、Whole-Body Dynamic Throwing（释放质量奖励）、GenRL（开局抖落与动作探索）。
