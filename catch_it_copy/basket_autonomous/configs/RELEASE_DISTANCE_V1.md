# 第二阶段释放距离奖励 v1

配置 mobile_release_distance_v1.json，从 fixed_fix 的固定抛 teacher_best.pth 使用 --initialize-from 初始化。不用旧移动模型，不新增训练阶段。

保留远距离移动配置：篮筐x[-.25,.25]、y[1.8,2.4]米，15秒回合，30%固定抛回放，导航进步权重12。

仅移动回合启用一次性 release_distance 项。确认物理释放后，用离手前最后接触时刻的底座 arm_base 到篮筐中心的水平欧氏距离结算。0.85～1.15米内奖励，区间内部距边界0.05米以上为+15，靠近边界线性减至0；区间外每偏离0.1米扣5，最多扣25。只有主动抛球才有正奖励，非主动掉球不能得正分；区间外确认释放仍扣分。每回合最多结算一次，重新接触不能重复领奖。

区间是沿用第一阶段目标范围的候选值，尚未标定真实最佳距离；可在新配置 range 中调整。进筐100及原释放/失败奖励保持不变。固定回放不新增距离奖惩，旧配置不启用此奖励。无持球辅助、无自动刹车、无新的动作/观测维度或释放门控。

评估记录 release_base_target_distance 为这项奖励实际使用的距离，reward_totals.release_distance 为累计奖励；无已结算释放则距离为null。
