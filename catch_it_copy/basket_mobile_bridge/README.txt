移动到投球区域后抛球的衔接版

独立包，不改变 basket_mobile_curriculum、basket_autonomous 的已有行为。
从 basket_mobile_curriculum 的66维、双输出头 checkpoint 通过 --initialize-from 导入权重。
推荐 teacher_last.pth。新优化器、学习率2e-5、步数从0计，所有参数可训练。
不要 --resume 旧包的 resume_last.pth；新包产生的 resume_last.pth 才能在这里续训。

初始课程level2：目标y1.6~1.9m；70%完整移动抛、20%固定抛回放、10%持球移动回放。
移动抛回合先调用已有持球头；底座水平距离.85~1.15m，原参考区域距离<=.05m，
球接触且位于支撑范围，相对滑速<.25m/s、底盘速度<.05m/s，连续.12秒后切换抛球头。
切换一次，奖励+5；不重置球、关节、控制目标或上一动作。底盘始终可控，不自动刹车。
切换前确认释放算失败，-20并取消抛球/弹道/进筐正奖励；保留距离惩罚和已有控制/持球等奖励。
切换后继续用原物理释放和进筐判据，v2距离奖惩保留。
这是显式策略切换规则，并非完全自主选择切换时机；没有锁球或环境持球力。

每25万步独立评估100回合；当前距离移动抛连续两次>=70%后扩大到y1.8~2.4m。
同时独立评估最终远距离移动抛。teacher_best按最终远距离成功率选择。
bridge_reached_sr：最近移动回合中成功切换到抛球阶段的比例。
mobile_sr：当前训练距离的完整移动抛成功率。
curriculum_eval_sr：当前距离独立评估，作为升级依据。
eval_success_rate：最终远距离独立评估。
混合success_100包含持球任务成功，不是单独的投篮成功率。

环境、导入权重、无物理重置切换、奖励一次结算、提前释放处理见 test_bridge.py。
