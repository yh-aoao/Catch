第二阶段持球移动课程（从已有固定抛初始化）

这是独立包，不修改 basket_autonomous 或 basket_three_stage 的已有行为。
入口：python -m basket_mobile_curriculum.run
配置：basket_mobile_curriculum/configs/tennis.json
观测66维（原65维+任务位，0=抛球，1=持球移动），动作仍20维关节速度/手指增量。
导入固定抛权重时扩展输入列为零；增加初始零输出的持球动作头，抛球均值策略保持原样。
所有参数均可训练；持球任务的手臂/手指探索标准差为抛球任务的5%，底盘探索不变。

课程由独立评估自动升级，不按训练步数强制升级：
level0: 目标y1.35~1.50m、x±.10m，70%持球移动、30%固定抛。
level1: 目标y1.60~1.90m、x±.25m，70%持球移动、30%固定抛。
level2: 目标y1.60~1.90m、x±.25m，10%持球移动、20%固定抛、70%完整移动抛。
level3: 目标y1.80~2.40m、x±.25m，10%持球移动、20%固定抛、70%完整移动抛。
固定抛回放始终使用原固定抛目标范围。每回合目标静止。

持球移动：目标进入底座坐标x±.10、y.85~1.15m矩形区域附近（到区域距离<=.05m），
接触支撑、相对滑速<.25m/s、底盘速<.05m/s，连续.30秒成功+30；失败-20。
保留原稳定/滑动/边缘、导航进步、控制和时间奖励，删除持球任务的弹道/释放/距离奖励。
确认释放则持球任务失败，不锁球不锁动作。确认释放仍采用原物理分离判据。
导航参考是宽松区域，并非唯一停车点；完整抛球保留v2距离奖惩和原进筐判据。

每250000步评估100回合。前两级持球评估连续两次>=80%升级；level2移动抛连续两次>=70%升级。
每次评估还单独测试最终远距离移动抛，其结果eval_success_rate才是完整远距离投篮能力。
metrics中的carry_sr/fixed_sr/mobile_sr分别统计各任务，success_100为混合任务成功率，不能当投篮成功率。
curriculum_eval_sr为当前升级考核。初期远距离投篮为零并不代表持球课程无进展。

teacher_best.pth按最终远距离移动抛成功率选择，不按持球成功率选择。
teacher_last.pth为最新定期保存；resume_last.pth含优化器和课程等级/升级计数。
promotion_levelN.pth保存升级时模型。升级后重建环境，清空旧回合奖励统计。
--resume读取保存配置和课程等级；重新从固定抛启动用--initialize-from。

不提供环境持球力、自动刹车、脚本手型、固定移动停车点或动作解锁。
当前是基于物理随机持球初始化，尚非在线接球后抛球。
