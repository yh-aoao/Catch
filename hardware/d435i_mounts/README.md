# D435i相机连接件：保留原项目几何的打印试装版

单位：**毫米**。STL本身不携带单位，切片软件中选mm、100%比例。原项目STL按米建模，本目录已转换成毫米，不能再放大1000倍。

## 应该打印哪几个文件

1. `d435i_hole_gauge_print_mm.stl`：建议首先打印的小试片，60×12×3 mm，两孔Ø3.4、中心距45 mm。确认两孔能同时对准实物D435i背部M3孔，然后再打印完整件。试片不作为实际支架。
2. `top_l3_d435i_M8_foot_print_mm.stl`：顶部连接件，保留原l3斜角结构，相机端两个Ø3.4通孔、孔距45；另在型材连接面新增两个Ø8.6通孔、孔距45，用于一条型材槽内的两个M8滑块螺母。配合你已有的4545欧标槽10型材使用，装前核对接触面/螺母与实物。M8孔不是小车固定螺孔，不能拿45 mm孔距当作车体接口。
3. `wrist_p1_d435i_FIT_PROTOTYPE_print_mm.stl`：腕部原p1连接板的孔位试装版，保留外形、3 mm厚度、法兰孔和长槽，只把相机两个Ø3.2孔扩大到Ø3.4。外包尺寸113×75×3 mm。

另提供 `top_l3_d435i_print_mm.stl`：不增加M8型材固定孔的保守版本，只修改原相机孔，用于已有其他固定方式的情况；其型材接触面与原文件相同，没有固定孔。两个顶部版本二选一。

`*_print_mm.stl` 已摆放到打印平台Z=0；同名不含 `_print` 的 `*_mm.stl` 保留原局部坐标方向，方便CAD装配。打印方向文件与装配坐标文件是同一零件，不要重复打印。顶部打印方向包围盒约67.5×41.47×80 mm；腕部113×75×3 mm。

## 原件实际已经有D435i孔距

来源：

- `catch_it_copy/assets/meshes/l3_Link.STL`：顶相机支架，两孔中心距45 mm，原孔为约Ø3.0的12边形通孔；斜面名义厚度5 mm。
- `catch_it_copy/assets/meshes/p1_Link.STL`：腕部连接板，相机孔在原局部坐标 `(X,Z)=(105,15)` 与 `(105,60)` mm，沿Y贯通，原孔约Ø3.2，中心距45 mm。
- XML装配依据：`catch_it_copy/assets/urdf/x1_xarm6_leap_right_object.xml`，l3与p1均与相机网格一起出现。

原相机网格约90×25×25 mm，与D435/D435i外形规格相符。因此不能仅依据“原项目使用D455”的描述就把这些STL当作D455孔位；本版以网格实测和D435i官方图纸为准，**没有移动相机孔中心**。只做打印孔间隙调整。保留机械安装面不等于已完成真实相机光学中心标定。

## 相机紧固件

官方D400数据手册October 2025，第140页Figure 10-9，D435/D435i：背部2×M3、孔距45 mm、最大螺丝伸入深度3 mm，推荐扭矩0.4 N·m。该扭矩是相机接口建议，不能当作打印支架已验证的拧紧扭矩。

来源：https://www.realsenseai.com/wp-content/uploads/2025/09/Intel-RealSense-D400-Series-Datasheet-October-2025.pdf

- 打印件是光孔，不攻M3螺纹。螺丝从支架背面穿过，拧入相机背部M3螺纹孔。
- 顶部安装面厚约5 mm，可从 **M3×8＋约0.5 mm平垫**开始核对，名义伸入2.5 mm。
- 腕部安装面厚3 mm，可从 **M3×6＋约0.5 mm平垫**开始核对，名义伸入2.5 mm。
- 实际伸入深度＝螺丝头下长度－打印件实测厚度－垫片实测厚度。拧入前实测，必须≤3 mm，并保证有效啮合，不以“能拧紧”判断长度合适。不要使用沉头螺丝配本版普通通孔。
- 顶部型材端采用M8螺栓、平垫、45系列槽10 M8滑块螺母。螺栓长度应结合支架5 mm厚度、平垫、螺母位置实测，不能直接沿用相机M3螺丝或其他8 mm转接板的用量。打印件在M8压紧处会发生蠕变，不靠大力拧紧补偿晃动。

## 打印与使用范围

可用PETG做孔位与装配试装，0.2 mm层高、至少5道壁、局部足够顶底层。填充、支撑、孔补偿需由实际打印工艺决定；顶部横向M8孔可能需要支撑或桥接调校。`_print`提供的是推荐摆放起点，不代表已经通过切片或实打印验证。Ø3.4为CAD名义值，打印成孔可能偏小。

**腕部p1带有机械臂/灵巧手连接孔。原3 mm板的材料与载荷额定值没有随STL公开，不能将这份3 mm塑料打印件当成可替代金属法兰转接板的承载件。** 腕部文件只用于静态孔位、空间和安装方向试装；承载灵巧手的主路径应保留经确认的金属连接，正式结构需另做强度和疲劳校核。试装时独立支撑灵巧手，不用这块打印板悬挂灵巧手运动。

顶部件也未做材料强度认证；先静态安装检查，拉线做应力释放，再检查USB-C插头空间、镜头/红外窗口无遮挡、末端全工作范围内的干涉和相机晃动。本版没有实机运动或装配碰撞验证。

## 检查与复现

`geometry_validation.json`记录：源文件SHA256、导出尺寸、孔壁顶点孔径、单一连通实体、闭合网格、法向一致性。布尔差集还验证了保守两款只修改相机孔（容许float32约0.001 mm³的数值残差）；M8版额外开型材孔。

`mount_preview.png`为几何预览和相机孔距示意。`generate_mounts.py`为可修改的参数化生成脚本。重建需要Python、numpy、scipy、trimesh、manifold3d、matplotlib；本次临时CAD库在 `/tmp/catch_camera_cad_deps`，未改训练环境。

这些检查证明文件几何有效，**不证明打印后实际适配、承载强度或实机接球安全性**。
