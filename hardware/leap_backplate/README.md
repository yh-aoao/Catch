# LEAP Hand v1右手后板：官方CAD及p1四孔适配候选

用户确认实物为右手。外形尺寸和手端固定孔尚未与实物量测核对。

## 文件选择

- `leap_v1_p1_4hole_candidate_print_mm.stl`：本次设计版。基于官网空白后板，保留手端所有原始结构，在官方xArm安装中心加入4个Ø7 mm通孔，35×35 mm正方形孔距，与本项目p1的四个较大法兰连接孔对应。无需加入原照片后板的中心方孔；本版保留官方空白板中央支撑实体。
- `leap_v1_official_xarm_print_mm.stl`：官方多机械臂适配版，仅改变打印摆放位置，包含更多安装孔。可作为备选，与设计版二选一，不需同时打印安装。
- 相同名称、不含`_print`的STL保留官方CAD的局部坐标；带`_print`文件将外侧平面朝下并放到Z=0。切片时单位mm，100%比例，不额外放大。
- `official/`保存官网原始STL/STEP，不修改原文件。
- `backplate_preview.png`为设计版孔距图，`official_comparison.png`对比官网两款原始后板。
- `validation.json`记录源文件哈希与验证结果，`build_backplate.py`可复现几何。

两款后板外包尺寸均约 **125×80×10 mm**。10 mm包含内侧凸台/边缘，并非整块板厚；外侧主体薄板约3 mm。手端固定孔、边缘、凸台均保留官方文件，不按照片重新猜测孔位。

## 为什么使用35×35 mm四孔

原项目p1四孔中心（原局部X,Z，单位mm）为(20,20)、(20,55)、(55,20)、(55,55)，原通孔约Ø6.8 mm。它们不是31 mm中央孔周围所有小孔组成的同一阵列。

官网xArm/Franka板同样包含35×35 mm四孔，孔径约7 mm。本次先从官方板孔壁拟合圆心，提取安装中心，再以官方空白后板开同样的四孔。安装中心在官方坐标约(X,Z)=(-48.72116,-39.72756) mm，未任意移动到板外形几何中心。

孔组能在平面内对应，不代表已确认手掌安装朝向。四孔阵列转90°仍能对孔，装配时要结合手掌朝向、p1相机伸出端和线缆方向确定最终角度，不能只看“螺丝能穿过去”。

## 装配关系与核对

机械臂法兰 → p1 → 新后板 → 灵巧手本体。

1. 先将新后板与现有黑色后板平放比较：外形约125×80 mm，手端固定孔必须对应，内侧凸台不得碰电机或线缆。本次已知是右手，不能据此跳过版本/孔位核对。
2. 不挂灵巧手负载，将p1与新板四孔叠放检查。手端内部这一侧需要容纳螺丝头和装配工具；计划用穿过后板、p1后拧入法兰的螺丝时，先核对整条路径，再组装手本体。
3. 官网装配说明涉及M3热熔铜螺母，本版保留相应孔/凸台。不能把所有孔都当作螺栓光孔，已有铜螺母也不要在未确认尺寸时强行装入。手端固定沿用对应版本的官方装配方式。
4. 法兰螺栓按实际螺纹及允许拧入深度选择；根据p1与后板实际叠厚、垫片测量所需长度。不要用过长螺丝顶住法兰盲孔底部，也不要让螺丝头压住内部电机/线缆。
5. 先独立支撑灵巧手做静态试装，检查后板贴合、螺丝啮合、线缆和工具避让，再决定正式材料和运动验证。p1和后板是串联承载件，只更换后板不会解决3 mm打印p1的承载问题。

这些是**试装候选模型**，未完成材料强度、疲劳、螺丝头内部空间及实机运动校核。官网打印建议不等于本项目接球冲击工况的强度保证。现有p1若为打印件，不应直接挂手进行快速接球；正式运动前应确认整条承载结构。
