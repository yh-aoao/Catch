# STL + XML 支架识别

直接解析二进制STL三角面顶点，并按XML无缩放网格的米单位换算为毫米；不是由照片估算。

| 文件 | 网格外包尺寸mm | XML装配位置/形状 |
|---|---|---|
| a1_Link.STL、a3_Link.STL | 45×1035×45 | 相机两侧立柱 |
| a2_Link.STL | 45×540×45 | 相机架横梁 |
| l1_Link.STL、l4_Link.STL | 45×45×45 | 相机立柱底部直角加强角件 |
| a4_Link.STL、a5_Link.STL | 45×315×45 | 机械臂底座下面的两根型材 |
| l6_Link.STL、l7_Link.STL | 90×45×45 | 机械臂底座区域左右两个宽直角加强角件 |
| Arm_base_Link.STL | 185×136×8 | 机械臂安装转接板 |

l6/l7为几何相同的左右安装件。网格显示约4mm板厚、约8mm圆孔，90mm方向双孔中心距约45mm。
l1/l4同样约4mm板厚、约8mm圆孔，45mm宽度单孔。
这些是三角面网格几何，不包括螺纹、公差、材料或制造商标号，不能凭8mm孔认定某种螺栓直接适配。

采购识别：l6/l7可按“欧标45系列4590加宽直角角码，90×45×45mm，双孔加强型”向商家索取图纸比对。
l1/l4可按“欧标4545直角加强角码，45×45×45mm”比对。
4590/4545是常见商品规格称呼，不是STL记录的确切品牌型号。确认孔位、壁厚、支撑筋、槽系和紧固件与实物相容。

装配依据：assets/urdf/x1_xarm6_leap_right_object.xml 第89–105、107–119行。
bracket_locations.png左图为机械臂底座，右图为相机立柱底脚；右图立柱仅为了显示截短，不修改原STL。
mount_candidates.png为各独立零件网格视图。

注意：如“两个支架”指转接板下方两根承载横梁，而非角件，则是a4/a5对应的4545×315mm型材，不是4590角码。
