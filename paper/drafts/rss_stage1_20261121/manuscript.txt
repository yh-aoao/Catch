# 预测辅助的多技能视觉移动灵巧接取与投掷
## 摘要
动态物体操作要求机器人在有限时间内协调移动底盘、机械臂与灵巧手。本文研究如何将多种接取情境与主动投掷整合到统一视觉学生中，同时保留专用策略的能力。我们通过两阶段强化学习训练四个专用教师：接取教师先学习跟踪再学习完整接取，投掷教师先在固定底盘条件下学习不同距离的投掷，再学习自主移动停靠与投掷；第二阶段继续优化已有参数。随后，冻结教师并联合蒸馏共享视觉编码与时序记忆的学生，以两个动作分支处理接取和投掷的控制差异。接取侧引入训练期当前位置监督，并将多时间步未来位移预测融入动作生成。本文提出可检验的技能保留与预测辅助假设，给出预算匹配的对照、分离消融和连续接抛验证协议。最终多技能对照与实机验证仍在进行，本文不将独立技能表现等同于已完成的人机往返交互。
## I 引言
接住人抛来的物体，再将物体送往指定位置，为人与机器人之间的远距离物体传递提供了一种操作形式。机器人既需要及时响应外部目标运动，也需要主动控制释放状态。移动底盘扩展可达范围，同时使拦截位置、机械臂姿态和手部接触时机相互耦合。相比仅掌握单项动作，面向实际传递的系统还需要在同一平台上保留接取与投掷两类技能。
Catch It 已展示移动底盘、机械臂和灵巧手协同接住飞行物体，并提出跟踪到接取的两阶段强化学习流程[1]。本文在这一基础上研究抛掷物体、桌面滚落和地面反弹三种接取情境与主动投框的视觉技能整合。
不同情境产生不同的运动变化与接触时序。仅靠当前图像难以确定来球运动，而将专用教师压缩至共享模型时，还需处理观测受限、数据不平衡与控制语义差异。统一模型减少独立策略的部署数量，但能否保留各技能、是否需要将运动预测直接反馈给动作生成，仍需受控实验回答。
我们采用多教师视觉蒸馏，将专用状态教师迁移至双视角深度与本体感知条件下的循环学生。共享主干学习感知与历史表征，Catch 和 Basket 两个动作头保留技能接口差异。当前位置 Aux 仅提供训练监督；Future 同时接受未来位移监督并参与接取动作生成。接取与投掷由外部指令选择，接取内部不输入运动情境类别。
本文检验两个核心假设。H1：在匹配每任务数据预算时，统一学生能够在减少部署策略数量的同时，将各任务相对专用视觉学生的成功率损失控制在预先声明的容许范围内。H2：在相同定位监督和训练预算下，未来位移监督及其动作融合能够改善接取表现。两项假设分别通过技能保留对照与预测分离消融检验，允许得到支持、部分支持或反证。
本文主要工作包括：（1）面向三种接取情境与主动投掷的共享视觉时序学习框架及分技能解码；（2）训练期定位监督与控制相关未来预测的组合设计及作用分解；（3）区分独立技能、连续接抛和人机交互的验证协议。实验将分别检验未来预测收益与技能整合代价。
## II 直接相关工作
**动态接取与投掷。** Catch It 利用状态输入与两阶段强化学习实现移动灵巧接取[1]。TossingBot 将物理模型与学习残差结合，研究目标投掷及物体变化[2]。本文沿用接取训练基础，研究接取与投掷的视觉学生整合，不将投框等同于向人回抛。
**专用策略整合。** Policy Distillation 将多个任务策略压缩至一个学生[3]；AutoMate 展示专用装配策略向通用策略整合的机器人学习流程[4]。本文采用类似的专用教师到共享学生范式，重点考察不同接取情境与主动投掷的控制差异。学生执行、教师标注的数据采集与 DAgger 的状态分布覆盖思想相关[5]，但有限 FIFO 经验与受限视觉观测不满足其理论结论的直接套用条件。
**表征监督与视觉策略。** 辅助任务为共享表征提供额外学习信号[6]。本文借鉴当前位置预测作为训练期监督的设计，不将其本身作为新算法贡献。【Aux 原始来源待补】Diffusion Policy 通过条件扩散建模视觉动作序列[7]；本文使用循环回归策略，并将其作为拟比较的外部方法之一，不将采集算法与网络结构混为同一对照。
## III 问题定义与研究假设
**任务。** 机器人由平面移动底盘、六自由度机械臂和灵巧手组成。任务集合 K 包含：（1）Throw：物体被外部抛出，机器人在飞行中接取；（2）Roll：接取沿桌面滚动并从边缘落下的物体；（3）Bounce：接取与地面碰撞反弹后的物体；（4）Basket：从持球状态自主移动、选择停靠位置并将物体投向指定目标。Throw 始终指接取任务，主动抛出对应 Basket。
**可用信息。** 学生输入 oₜ=(Dₜ,pₜ,aₜ₋₁,cₜ)。Dₜ 为双相机深度，pₜ 为底盘速度、末端位姿与速度、机械臂关节状态和手部状态，aₜ₋₁ 为上一执行命令。cₜ 包括外部 catch/basket 指令，投掷时还提供目标相对位置与执行阶段状态。接取时关闭投掷专用条件。学生不输入物体真实位置、速度、身份或动力学参数。
投掷教师自主选择停靠位置，不以唯一预设停车点作为任务前提。停靠选择与阶段切换是不同问题：若导航与投掷切换仍由外部调度器提供，该信号须计入所有比较方法的可用观测。【新版学生阶段接口待核对】实机需通过目标定位与机器人反馈复现这些输入，本文不声称纯视觉意图识别。
**控制接口。** Catch 输出底盘平面速度2维、末端控制6维与手指12维；Basket 输出底盘速度2维、关节速度6维与手指12维。两个20维动作向量经各自适配器执行，共享模型保留了不同的物理动作语义，技能选择由外部指令控制。
**假设的判定。** 对 H1，计划将逐任务容许损失设为5个百分点，并报告统一学生与专用视觉学生成功率差的区间；该阈值在最终测试前固定，用于衡量部署时可接受的技能损失。区间过宽时结论为证据不足。对 H2，分别比较动作模仿、加入定位监督、再加入未来监督、最后加入预测动作融合，逐项报告差值；仅预测误差下降不视为控制收益。
## IV 方法
### A 两阶段专用教师
四个教师分别训练。接取第一阶段学习底盘与机械臂跟踪接近目标，第二阶段加入手部控制学习接取，并继续优化已有参数。Throw 沿用原项目，Roll 与 Bounce 调整物体运动及任务奖励。训练完成后教师冻结。
Basket 第一阶段固定底盘，在训练中改变篮筐前后位置，使机械臂与手部学习面向不同距离的投掷；第二阶段开放底盘移动，同时继续训练第一阶段参数，学习停靠位置与投掷动作的配合。该分解先建立释放控制，再引入位置选择。减少联合探索难度是设计动机，是否优于直接联合训练需要专门对照。
### B 共享学生与技能分支
两个深度视角分别编码为128维特征，与36维本体状态、20维上一动作及任务条件拼接，输入256维 GRU。条件编码中屏蔽无效目标，防止目标编码器偏置将投掷信息带入接取。学生与两个动作头从首轮共同训练，不先预训练接取再追加投掷。
@ h_t = GRU_θ([E_1(D_t^1),E_2(D_t^2),p_t,a_{t−1},e(c_t)],h_{t−1}).
上式用作数据流定义；具体拼接在实现中完成。Basket 动作头直接使用 hₜ。Catch 在 hₜ 上融合未来预测，最后以任务指令选择动作。技能切换不依赖 Throw/Roll/Bounce 标签。回合重置清空 GRU 与上一动作；连续接抛的切换单独验证。
### C 训练期当前位置监督
位置头 Ppos 从 hₜ 估计物体在机械臂基座参考系下的位置 qₜ，以仿真标签计算尺度归一化的 SmoothL1 损失。当前位置输出不进入动作头；辅助损失通过共享主干间接影响策略学习，推理时可省略该头。已有接口含位置与速度输出，但当前配置只启用位置监督，速度项不参与当前优化。
@ !q_t = P_{pos}(h_t),    L_{pos} = ρ(!q_t/s_q − q_t/s_q).
ρ 表示逐维平均的 SmoothL1，s_q 为固定位置尺度。该分支沿用已有辅助预测思想[6]，具体位置预测设计的原始来源标记为待补。本文检验的是它在本框架中的作用及与未来预测的关系。
### D 多时间步未来位移与融合
Future 头为256→128→9的多层感知机，输出1、3、5个策略步后的世界坐标物体位移。设物体世界位置为 xₜ，则
@ Δx_t^{(j)} = x_{t+j} − x_t,    j ∈ {1,3,5}.
@ Δ!X_t = P_{future}(h_t),    ~h_t = h_t + W_f Δ!X_t + b_f.
Catch 由融合表征 h̃ₜ 生成动作。该结构将预测特征用于回归控制，不运行独立轨迹规划器。预测头同时接受未来标签梯度与动作模仿梯度；“仅 Future 监督”消融移除动作融合路径，其余设置相同。
标签仅在同一回合且目标时刻之前尚未发生首次手接触时有效；桌面与地面碰撞仍保留。首次手接触后停止显式未来监督，但预测与融合仍参与动作计算。设有效掩码为 mₜ⁽ʲ⁾，当前实现按固定回合长度和预测跨度平均：
@ L_{future}^τ = (1/(|τ| |H|)) Σ_{t∈τ,j∈H} m_t^{(j)}ρ(Δ!x_t^{(j)}−Δx_t^{(j)}).
因此掩码覆盖比例影响损失有效强度；消融同时报告有效标签比例，避免将样本覆盖变化解释为模块能力变化。
### E 学生交互与任务平衡
学生执行动作，教师对同一状态提供标签。各任务/物体独立 FIFO 回放，任务等权、物体等权采样，回合内按长度平均，不让长回合或更多物体自动增加任务权重。输入目标、标签与动作适配采用对应教师约定。
归一化教师动作 y∈[−1,1]，学生 logit 为 z，单维模仿项为2 BCEWithLogits(2z,(y+1)/2)。分别平均底盘、机械臂和手部动作组，再对当前有效动作组等权平均。若 Basket 保留阶段动作屏蔽，比较方法使用相同屏蔽，以隔离策略学习与调度器的影响。
@ L = Σ_{k∈K}w_k[L_{imit}^k + I_c(k)(0.1L_{pos}^k+0.1L_{future}^k)].
I_c 在三个接取任务为1，在 Basket 为0。默认训练设置为每任务6个环境、采集64步、每轮8次更新、BPTT长度16，共10000轮。学习率前5000轮为3×10⁻⁴，之后余弦降至3×10⁻⁵。5000轮起每1000轮验证，每任务300回合。上述为现有蒸馏设置，新教师适配后冻结最终配置，不依据测试结果回调。
## V 验证设计与预期辨别力
### A 当前证据与结果使用边界
当前已实现四任务学生训练与评估，以及不重置物理状态的接取后投框串接基线。新版教师与学生的最终匹配评估仍在进行，因此本稿重点呈现方法与验证协议。历史版本的不同教师与成功指标分开处理，所有正式结果将绑定检查点、配置、任务指标与测试实例，不混合报告不同版本的能力。
首轮验证将优先检验 H1 与 H2。训练种子与评估种子分开：拟对关键变体进行3次独立训练，最终每模型每任务测试1000回合；训练期每任务300回合仅用于验证和选点。对多物体任务采用物体宏平均，并分别报告物体结果。随机物理实例与其重复发射分层统计，不把所有回合视为独立参数样本。
### B 预算匹配的技能保留对照
状态教师作为特权信息参考，不与视觉学生宣称同条件优势。专用视觉学生、普通联合学生和完整方法使用相同教师、观测及动作接口。报告每任务成功率、相对专用视觉学生差值、部署参数总量和实测控制延迟。四个独立视觉模型与一个共享模型的成本按完整部署集合计算。
三情境接取学生与四任务学生采用两种预算条件：总交互一致，以及每项接取数据一致。前者反映固定资源代价，后者检验新增 Basket 后的共享干扰。外部 Diffusion Policy 基线匹配教师数据与输入，合理选择动作序列执行长度，并把闭环延迟计入，使序列执行方式适应动态接取的反馈需求[7]。
! 表I 辅助设计的因果对照矩阵
| 变体 | 位置监督 | 未来监督 | 动作融合 |
| 联合模仿 | 无 | 无 | 无 |
| Aux | 有 | 无 | 无 |
| Aux＋Future监督 | 有 | 有 | 无 |
| 完整方法 | 有 | 有 | 有 |
所有变体保持共享主干与采集预算一致。按任务报告成功率差与训练种子间变化，预测误差按跨度及有效区间统计。只有完整方法相对 Aux＋Future监督的差异才能用于讨论融合收益；以区分定位监督、未来监督及动作融合的贡献。
### C 泛化与移动作用
分别测试训练内条件、未见物体身份和物理参数变化，明确是否属于未见形状类别。测试生成多个独立物理实例，在相同实例及发射条件上比较方法。教师的泛化结果单列，与学生结果分开报告。任务成功指标保持一致，Roll 的区域保留与稳定握持分别报告，Basket 区分释放、命中与完整成功。
投掷改变目标距离，记录成功率、停靠位置和释放状态。若需主张移动带来收益，进一步比较固定底盘和可移动底盘，分别统计固定底盘可达与不可达条件，控制初始持球与目标设置。自主停靠的价值由该对照检验，并结合轨迹分析解释。
### D 连续接抛与人机交互
连续接取后投框基线保持同一物体与物理状态，不调用重置；切换时清空循环记忆，使用接取后的实际持球姿态。稳定接取检测使用接触、相对速度及持续时间，该调度器计入系统组成。接口一致性检查仅说明切换未重置状态，不代表任务成功。
实机先分别测试接取和投掷，再测试连续往返。统计接取率、成功接取后投掷的条件成功率和以所有尝试为分母的全流程成功率。投框不能直接称为回抛给人；后者需提供接收目标并预先定义可接区域或实际人接住的标准。若只能完成独立技能，结论限定于技能基础，不宣称多轮交互。
### E 反证与失败分析
若未来误差下降而成功率不变，将比较接近、首次接触与接触后控制失败比例，检验性能是否受握持而非运动估计限制。若四任务退化，利用预算对照区分数据减少与共享干扰，再检查动作组及阶段覆盖。通过上述对照区分数据覆盖、表征共享与接触控制等解释，形成对假设失败原因的证据。
## VI 结论与局限
本文提出以专用教师到共享视觉学生为主线的移动接取与投掷框架，并将定位监督、未来预测和动作融合分开检验。首轮稿给出可执行的方法与假设验证协议，最终能力与预测收益等待匹配实验确认。外部任务/阶段输入、有限物体覆盖、任务指标差异及接取后的持球分布偏移构成当前边界。连续人机往返接抛仍是需验证的系统目标。
